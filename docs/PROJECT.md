# 后续科研项目背景（不是笔试交付范围）

RealityLoop 面向生命科学、化学、环境、材料等湿实验场景，研究从实验视频到结构化过程理解、偏差识别和及时提醒的闭环。长期能力层级为 Perception、Action、State、Procedure、Error、Anticipation、Intervention。

数据规划：结合获得适当使用许可的公开湿实验数据、可依法使用的网络视频与一手实验室数据。计划建设 50–100 小时、覆盖多个实验室和实验类型的一手数据；这里是规划目标，不是当前已经完成的资产声明。网络 VLM 自动标注主要用于训练或标注建议，最终基准与隐藏测试以专家标注、复核的一手数据为主。

50–100 小时应优先定义为去重后的实验时间：同一个实验同时录制五个机位，1 小时实验时间仍为 1 小时，而不是 5 小时。另行披露原始摄像机总时长、有效操作时长、人员/协议/设备/实验室数量以及每类错误事件数。只有视频时长而没有足够错误事件和正常负例，不能支持错误预警评估。

标注对象包含：物体/仪器实例、原子动作、可观察状态与状态转移、SOP 对应关系与完成情况、时间边界，以及错误类型、最早可见证据、可能不可逆时点、严重程度和证据来源。PNR 依赖可执行干预，不能仅凭事后视频任意标注。

泛化评估分别考虑 Seen/IID、Unseen Operator、Unseen Protocol、Unseen Equipment、Unseen Lab、Unseen Error/Protocol Variant。划分以完整实验及其全部机位为最小分组，防止相邻片段、同次实验的其他视角、同一网络视频的重剪版本泄漏。

阶段安排采用依赖关系，而不是承诺已经完成的历史日期：先确认数据与标注边界、整理许可和预处理；再冻结基线、任务与评测；在专家测试集隔离的前提下做小规模后训练与消融；最后根据结果决定是否扩大数据、模型或训练策略。避免“先训练，训练完再决定测什么”。

招聘后可以根据能力分工为数据与 Benchmark、视频理解与后训练、因果时序与错误预警三个方向。1–3 人并不要求每个人独立完成全部七个能力层级。
